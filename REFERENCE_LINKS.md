# Reference links and included NASA documents

The Git repository keeps reference URLs and notes. The complete release bundles include only the four selected NASA government publications listed below. Manufacturer, simulator, conference and externally authored NASA-hosted works remain link-only; their full PDFs are not reproduced in those bundles.

Download the bundles from [release v0.1.0](https://github.com/0xlillith/solidcraft-fa18c-stennis/releases/tag/v0.1.0).

All original modeling code and geometry are included. Reference PDFs are optional reading; rebuilding the geometry does not require downloading the link-only sources.
