# Original portable archive provenance

These two files are copied unchanged from the verified model archive.
Their paths and hashes describe the complete extracted portable project,
including generated OBJ files, native scenes and its original documentation.
They do not describe the smaller Git checkout or its publication-edited README.

To check the complete extracted project, run sha256sum -c SHA256SUMS.txt
from that project's root. Release-asset checksums are in
[../release/SHA256SUMS.txt](../release/SHA256SUMS.txt).

The verification records retain original authoring paths as historical evidence;
those paths are not dependencies for opening the self-contained native models.
