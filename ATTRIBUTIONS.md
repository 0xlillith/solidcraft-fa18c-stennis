# Attribution and license scope

## Original project work

The procedural model generators, mesh geometry, geometric lettering, display graphics, and artist-selected material appearances were created for this F/A-18C / Stennis project under the 0xlillith account.

This repository currently declares **no open-source or Creative Commons license for the original project work**. This attribution file adds no license or redistribution grant. Third-party reference works retain their own notices and terms.

The scene uses independently authored geometry. No DCS game mesh, simulator texture, screenshot, OpenHornet CAD/SVG path, downloaded aircraft model, or reference photograph is embedded in the model.

## Historical notes and current revision

The documents under `docs/research/` were recovered from the first showcase project's reference records. They are retained as historical reference notes. Their original statements about earlier cockpit controls, build output, packaging, and motion estimates are not substitutes for the current RC3 documentation and validation records. Their addition to this repository changes documentation and attribution only; it makes no geometry or mechanism change.
