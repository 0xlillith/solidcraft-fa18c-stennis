# F/A-18C / USS John C. Stennis — SolidCraft 0.40 RC3

Initial dedicated repository release of the detailed visual and kinematic model.

## Download

- **FA18C_Stennis_RC3_Master.sc** — complete aircraft and Stennis launch scene.
- **FA18C_RC3_Aircraft.sc** — complete aircraft without the carrier.
- **FA18C_RC3_Cockpit.sc** — canopy open, pilot hidden, cockpit accessible.
- **FA18C_RC3_Internal_Systems.sc** — installed systems exposed.
- **FA18C_RC3_Structure.sc** — additional equipment hidden to expose structure.
- **F404_RC3_Engines.sc** — both engine cores exposed through casing and liner cutaways.
- **FA18C-Stennis-RC3-Realism-20261109.tar.xz** — complete compact portable project.
- **FA18C-Stennis-RC3-Realism-20261109.zip** — complete standard ZIP project.
- **SHA256SUMS.txt** — checksums for all eight downloadable model/project files.

Open native files in **SolidCraft 0.40.0-rc.3**. They use **solidcraft/51**. All six files were saved and reopened with the verified official RC3 executable.

The master contains 914 components, 3,208 material-separated bodies, 3,151,204 triangles, 931 assembly joints, 400 motion links, 20 saved views and 15 motion studies. All 343 tested independent drivers moved and restored their launch positions, with zero reported joint conflicts or floating chains.

The repository contains editable procedural source, the scene manifest, material/reference notes and verification records. Generated OBJ files, native binaries and selected NASA reference PDFs are supplied in the complete project bundles. GitHub's automatic source-code archives contain the Git checkout; use an explicitly attached complete project bundle for all generated model files.

This is a mesh-based visual and kinematic reconstruction. Published facts, replica-derived measurements, authored internal geometry and material proxies are distinguished in the documentation. Flight-control software, avionics, combustion and aircraft performance are not simulated.

The native models and complete project bundles preserve the verified delivery bytes. Repository documentation adds corrected navigation and inherited carrier reference notes. Manufacturer, simulator and other link-only references are listed with source URLs; no DCS or OpenHornet model geometry is embedded.
